# 🌐 maomaowang.top

**短域名** —— 访问 `maomaowang.top` 会自动跳到主站 **maomao1ovo1.github.io**。

| 项 | 说明 |
|---|---|
| 用途 | 给「毛毛的个人主页」一个好记、好念、好分享的短地址 |
| 实现 | 一个纯跳转页 + `CNAME`（GitHub Pages 自定义域绑定） |
| 主站 | 👉 https://maomao1ovo1.github.io |

## 文件
- `index.html` —— 跳转页（打开即跳主站）
- `CNAME` —— GitHub Pages 的自定义域名

> 想给自己的站做同样的事：写一个带 `<meta http-equiv="refresh">` 的跳转页，再把域名的 CNAME 解析指向 `<你的用户名>.github.io` 即可。
